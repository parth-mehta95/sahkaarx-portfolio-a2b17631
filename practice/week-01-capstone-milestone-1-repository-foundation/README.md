# Capstone Milestone 1: Repository Foundation

## Task Brief
Scaffold the AI Engineer Foundation Repository with clean structure, initial documentation, and demonstrated PR workflow.

## Scenario
Your portfolio needs a professional GitHub repo showing version control mastery and readiness for collaborative AI projects.

## Deliverables
- Public GitHub repo with descriptive README
- Main and develop branches established
- First merged PR demonstrating workflow

## Success Criteria
- Repo is public, cloneable, and well-documented
- Branch strategy is clear and followed
- PR workflow is demonstrated with meaningful commits
