# Capstone Milestone 3: Branching and Merging Workflow

## Task Brief
Establish a professional branching strategy, create multiple feature branches, and merge them cleanly into main.

## Scenario
Your team uses feature branches for parallel development; you must manage multiple branches and merge them systematically.

## Deliverables
- 3+ feature branches with distinct changes
- Multiple merged PRs to main
- Clean commit history with descriptive messages

## Success Criteria
- All branches merge cleanly to main
- Commit messages follow clear naming convention
- Repository shows professional branching strategy
