# Capstone Milestone 4: Pull Request Review and Collaboration

## Task Brief
Practice professional PR review workflows by creating PRs with detailed descriptions, requesting reviews, and incorporating feedback.

## Scenario
Your team requires thorough PR reviews before merging; you must create detailed PRs and demonstrate collaborative review practices.

## Deliverables
- PR with detailed description and context
- Review comments and feedback incorporation
- Merged PR with clean history

## Success Criteria
- PR description clearly explains changes and rationale
- Feedback is addressed in follow-up commits
- Final merge shows professional collaboration
