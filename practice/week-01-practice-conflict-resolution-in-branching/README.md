# Practice Conflict Resolution in Branching

## Task Brief
Create overlapping branches, intentionally trigger merge conflicts, and resolve them using Git commands and best practices.

## Scenario
Two team members edit the same file; you must resolve conflicts and merge cleanly to main.

## Deliverables
- Two feature branches with conflicting edits
- Resolved merge with conflict markers removed
- Documentation of resolution steps

## Success Criteria
- Conflicts are identified and resolved correctly
- Final merge is clean with no conflict markers
- Resolution process is documented in commit message
