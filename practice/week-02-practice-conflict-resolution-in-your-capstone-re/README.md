# Practice Conflict Resolution in Your Capstone Repo

## Task Brief
Create overlapping branches, trigger merge conflicts intentionally, and resolve them using Git best practices.

## Scenario
Two team members edit the same file in your capstone repo; resolve conflicts and merge cleanly.

## Deliverables
- Two feature branches with conflicting edits
- Resolved merge with clean history
- Conflict resolution documented in commit

## Success Criteria
- Merge conflict detected and resolved without errors
- Commit history shows clear resolution steps
- Both changes integrated logically into main
