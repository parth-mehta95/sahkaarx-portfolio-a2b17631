# Practice Demonstrating All Basic Git Commands

## Task Brief
Execute and document all essential Git commands through meaningful commits in your capstone repository.

## Scenario
Your team requires evidence of Git command mastery; demonstrate add, commit, push, pull, status, and log in your capstone.

## Deliverables
- Series of commits using all basic Git commands
- Documented Git workflow in repository
- Clean command history showing proficiency

## Success Criteria
- All basic Git commands executed and committed
- Commit messages clearly describe each command used
- Repository shows progression of Git skill development
