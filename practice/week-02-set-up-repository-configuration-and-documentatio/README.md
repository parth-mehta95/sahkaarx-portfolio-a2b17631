# Set Up Repository Configuration and Documentation

## Task Brief
Configure your capstone repo with .gitignore, README, and demonstrate all basic Git commands through practice commits.

## Scenario
Your team lead requires proper repo setup with documentation and clean commit practices for the capstone.

## Deliverables
- Updated .gitignore for Python projects
- Comprehensive README with project overview
- Multiple practice commits demonstrating Git commands

## Success Criteria
- Repository properly configured and documented
- All basic Git commands demonstrated in commits
- Clean, descriptive commit messages throughout
