# Practice Atomic Commits and Branching

## Task Brief
Create feature branches and write atomic commits with clear messages in your capstone repo.

## Scenario
Your team requires clean commit history; create feature branches and demonstrate atomic commits.

## Deliverables
- Feature branch with 3+ atomic commits
- Clear commit messages following conventions
- Commits pushed to remote

## Success Criteria
- Each commit addresses one logical change
- Messages follow format: type(scope): description
- All commits visible in git log
