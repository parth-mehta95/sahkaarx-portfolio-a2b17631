# Practice Merging Workflows

## Task Brief
Merge feature branches into main using pull requests and document the complete workflow.

## Scenario
Your team uses PRs for all merges; create PRs, review, and merge your feature branches cleanly.

## Deliverables
- 2+ merged pull requests to main
- Clean merge history without conflicts
- Workflow documentation in README

## Success Criteria
- PRs have descriptive titles and descriptions
- Merges complete without manual conflict resolution
- README documents branching and merge strategy
